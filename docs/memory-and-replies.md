# 自然回复与个人记忆

更新：2026-11-02。本文描述当前实现，运行和验证记录见[开发与验证](development.md)。

## 自然回复

默认规则集中在 `src/server/agent-prompt.ts`，各渠道共用。简短聊天直接接话，复杂问题保留必要细节；口头禅、语气词和表情只在合适时使用，不固定开场、结尾或追问。提示词包含轻松回应、情绪承接和操作失败的尺度示例。用户保存的名字和系统提示词每轮读取，本轮明确要求优先；设定只影响角色与表达，不改变权限和业务事实。

失败如实报告，不用表情代替操作结果，不编造真人身份、个人经历或识图能力。表情仍从四张真实素材选择，沿用每轮一张、相邻已完成轮次不重复同一张和开关限制。微信聊天表情工具仍关闭，首次接入欢迎图是独立渠道功能。

DSH 的风格模板生成思路用于参考，本项目没有复制整段上游 Prompt 或插件源码，没有自动采集聊天风格、额外风格模型、随机延迟或逐句发送。相同 Prompt 不能保证不同模型输出同样效果。

## 信息边界

| 信息 | 存放与用途 |
| --- | --- |
| 助手设定 | `user_preferences`；名字、角色、整体语气与能力开关，每轮生效 |
| 聊天上下文 | `runs`；最近对话帮助理解指代，清空聊天后不再使用 |
| 长期记忆 | `memories`；用户明确要求保存的独立事实、长期目标、偏好或约束 |
| 业务记录 | 待办等各自的表；是否保存、完成，以业务工具的当前结果为准 |

“记住我不喝含糖饮料”可以保存；“这次先简短说”只影响本轮。临时情绪、助手推测、引用、写作素材和角色扮演不作为用户经历自动保存。记忆中的个人事实按用户自述使用，不冒充已核实的业务结果。

## 最小实现

复用 PostgreSQL 现有表，不新增数据库、向量服务、记忆摘要或后台抽取。`memories.ts` 管读取、去重、版本和归属；网页与 Agent 写入共用这些规则。

1. **保存**：每条表达一个独立事实，最多 1,000 字符、每账号最多 100 条。仅空白格式不同的相同内容复用原记录，并发提交也不重复创建。更新成另一条已有内容时报冲突，不静默合并或删除。
2. **读取**：不自动注入整库或近期摘要。需要历史信息、长期偏好或写入前查重时，模型调用 `list_memories({ query, offset })`。关键词按字面包含匹配，忽略大小写、统一空白；空查询浏览全部。每页最多 10 条，返回完整正文、ID、版本、匹配总数和下一页位置；不能把一页说成全部。
3. **纠正**：查到原记录后按 ID 和当前版本修改，例如将“咖啡加糖”改为“咖啡不加糖”。版本冲突先重读。同义和矛盾判断由当前 Agent 结合指令完成；服务端保证确定的去重与并发规则，尚无语义合并。
4. **忘记**：删除后，后续查询不再返回，也没有后台任务自动补回。再次记住需用户新的明确要求。原聊天文字和界面操作记录保留，清空聊天是另一项操作。
5. **开关与隔离**：关闭记忆后，下一轮移除全部记忆工具；手动管理仍可用，符合现有产品约定。查询按账号隔离，写入校验账号、版本及运行状态。已经开始的一轮沿用启动时的配置快照。

模型上下文不再重复附带旧的保存、修改、删除记忆工具结果，避免旧正文再次作为“已确认操作”传入。原用户消息和助手回复仍可能出现旧内容；提示词要求以当前记忆查询和用户本轮纠正为准，不能把旧文字当作有效长期记录。

## 对 IELTS Buddy 的取舍

参考 IELTS Buddy 本地工作副本（检查时 HEAD 为 `71a340cc`）的记忆系统文档、简化及语义召回记录，并核对记忆服务、检索服务和 Agent 指令。只借鉴设计原则，不移植其账号、学习业务或源代码。

| 参考机制 | 当前项目的处理 |
| --- | --- |
| 原子记录是唯一长期事实源，移除无消费者的画像摘要 | 采用；一条正文表达一个事实，无额外摘要表 |
| 记忆、显式个性化和真实业务证据分开 | 采用；助手设定独立生效，待办有独立业务表 |
| 按需检索、保留完整正文 | 采用；关键词查询和明确分页，普通闲聊不预读记忆库 |
| 同一事实更正、旧数据不能覆盖新陈述 | 采用 ID 与版本校验；暂无问卷和异步抽取，不新增 subjectKey 分类体系 |
| 删除反馈阻止后台重新生成 | 当前无自动生成链路，直接删除；以后如增加自动抽取，须先补删除抑制和来源时间规则 |
| 语义向量、问卷同步、自动抽取、有效期 | 暂不引入，先满足当前 100 条显式记忆的需求 |

关键词检索不具备语义同义召回能力。未命中可换关键词或浏览列表；实际使用频繁漏掉同义表达时，再据案例增加语义检索。当前没有自动过期，日期类承诺应使用业务能力，不能把记忆当提醒。

## 验证边界

自动化覆盖并发去重、账号隔离、请求冲突、版本更新、容量、完整正文、查询翻页、忘记后查询、旧快照处理，以及真实数据库上的 AI SDK 工具循环。模型部分使用测试替身，不能证明自然度或自主选工具的质量。

真实模型待复核场景：轻松庆祝、低落时不说教、明确要求详细解释、工具失败如实报告、重复记住同一偏好、更正原偏好、忘记后新对话查询、关闭记忆后询问旧偏好。使用独立测试账号，同组输入比较默认设定和用户设定；目前没有本轮自然度盲评结论。
