# 自然回复与个人记忆

各渠道共用 `src/server/agent-prompt.ts` 的表达规则。用户保存的助手名字和系统提示词在每轮开始时读取，改变语气与表达，不改变身份、工具权限或业务事实。工具失败必须如实报告；表情只能从项目固定素材中选择，受账号开关和每轮数量限制。

长期记忆位于 `memories` 表，只保存用户明确要求记住的事实或偏好；事项等业务结果保存在各自的表。网页和 Agent 复用 `src/server/memories.ts` 的账号归属、去重、容量与版本规则。模型需要时通过工具查询记忆，每页最多十条，不自动读取整库。

纠正记忆时按 ID 和当前版本更新；删除后后续查询不再返回。旧聊天文字仍可能包含该内容，清空聊天须单独操作。关闭记忆开关会移除下一轮的记忆工具，不删除已有记录，网页手动管理仍可用。当前关键词查询不支持语义同义召回，也没有自动画像或记忆过期。

模型与渠道的自动化检查使用替身；自然度、真实模型选工具的质量和长期使用效果仍需用户场景验证。
