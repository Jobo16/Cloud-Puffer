# 工作区使用说明

适用于当前开发预览版。项目首页位于 `/`，登录后的工作区位于 `/app`。托管服务尚未公开；本地启动见 [README](../README.md#本地运行)。

## 进入工作区

在首页打开登录或注册浮窗。注册使用邮箱和密码，不需要邀请码，验证邮箱后进入工作区。本地验证和密码重置邮件在 [Mailpit](http://localhost:18025) 查看。

桌面端左侧是导航，右侧是当前页面。一级入口按使用频率排：对话、事项、记忆、助手。对话就是主界面，网页和微信共用这一条记录；事项和记忆是独立列表；名字、系统提示词、能力开关和渠道绑定都收在「助手」里，页内用「设定 / 接入」切换。手机端同一套入口收在左侧菜单里：点左上角按钮滑出，选完自动收起，点遮罩或按 Esc 关闭。首页因此只有菜单按钮、居中的页名和输入框。

左下角是个人入口：点头像向上弹出菜单，能看到账号、今日对话用量、修改密码、开源仓库和退出登录。手机上没有侧栏，同一个入口放在顶栏右侧，向下弹出。用量不再常驻侧栏，需要时再展开。

对话页使用账号的真实主对话。这里发起的操作会修改真实待办和记忆，并按同一规则计算对话额度。消息从网页发起，普通回复不会额外推送微信或 QQ；已绑定渠道的对话会同步显示在网页。切换页面时聊天组件保持挂载，草稿和滚动位置都还在。

## 配置助手

1. 打开「助手」，在「设定」里编辑名字和系统提示词。
2. 选择需要的能力。改动在停止输入约半秒后自动保存，无需手动提交。
3. 回到「对话」发消息，查看下一轮回复。

| 配置 | 用法与限制 |
| --- | --- |
| 助手名字 | 默认 `JOJO`，去除首尾空格后不能为空，最多 40 字符；改动后聊天标题随之更新。 |
| 系统提示词 | 一段文字描述角色、性格、说话方式和回答习惯，最多 4,000 字符；留空沿用默认个人助手设定。 |
| 待办事项 | 默认开启；关闭后，助手不能调用待办查询、创建、修改和删除工具。 |
| 长期记忆 | 默认开启；关闭后，不读取记忆库，也不能调用记忆工具。 |
| 表情回复 | 默认开启；用于网页和 QQ，每轮最多一张，避免连续使用同一张；微信目前只回复文字。 |

例如可以写「温和、直接的生活搭子，回答简洁；整理复杂问题时先给结论，再列必要步骤」。这段文字调整表达方式，不增加工具、跨账号访问或执行代码的权限。

配置按账号保存，Web、微信和 QQ 共用。每轮回复开始运行时读取配置；正在运行的回复不会因修改系统提示词或待办/记忆开关而重新开始。表情还会在选择和 QQ 图片发送前检查开关。

配置改动自动保存，切换页面或关闭窗口时会补存最后一次未落盘的改动；保存失败在页面底部提示，输入内容保留。聊天草稿切换页面仍保留，刷新不恢复。

## 管理已有资料

- 「事项」可手动创建、编辑、完成和删除待办，也能看到助手替你记下的条目。截止时间只是事项信息，当前不会触发提醒。
- 「记忆」可查看、添加、修改和删除明确保存的偏好。助手只在用户明确要求时保存记忆。
- 关闭工具开关不会删除资料，也不影响手动管理。关闭记忆或删除某条记忆不会清除聊天中已出现的内容；清空聊天是另一项操作。
- 「助手 › 接入」管理微信和 QQ 绑定，只在需要时打开，不占一级入口。
- 清空主对话在「对话」页顶栏，需要确认。它不删除独立保存的事项和记忆，也不恢复当天额度。

## 聊天与渠道状态

聊天支持逐步显示回复、查看已完成操作、停止当前运行和加载更早历史。停止不会撤销已经保存的操作。同一账号的消息按顺序处理；暂时离开网页不会取消已接收的任务。

当前开发预览默认每天 50 次对话，北京时间零点更新，用量在左下角个人菜单里查看。成功接收进入队列的请求会占用额度，包括后续失败或取消；模型未配置、额度不足等被拒绝的请求不计入。平台可调整限额。

微信和 QQ 默认关闭。平台启用后，用户在「助手 › 接入」扫码绑定微信，或生成一次性指令并在 QQ 私聊发给平台机器人。两个渠道均只处理受支持的私聊文字，文件、语音、识图和群聊尚未开放。微信和 QQ 的真实账号收发仍需验收。

「已同步」表示网页当前能获取账号状态，不代表模型已连接或渠道已送达。渠道记录中的「已提交」仅代表接口接受；「未发送」「失败」「结果不确定」保留在网页，不自动重复发送未知结果。

## 对话服务尚未连接时

默认本地配置未接入模型，仍可保存助手设定、手动管理事项和记忆。聊天提示服务不可用，不会生成模拟回复；发送失败保留输入。

维护者需要选择模型供应商，并按 [开发配置](development.md#配置边界) 设置服务端参数、重启 Web 和 Worker。用户的「系统提示词」不是模型连接设置。提醒、搜索、文件和文档功能的进度见 [开发与验证](development.md#待完成)。
