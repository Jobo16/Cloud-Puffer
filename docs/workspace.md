# 工作区使用说明

适用于当前开发预览版。项目首页位于 `/`，登录后的工作区位于 `/app`。托管服务尚未公开；本地启动见 [README](../README.md#本地运行)。

## 进入工作区

在首页打开登录或注册浮窗。注册使用邮箱和密码，不需要邀请码，验证邮箱后进入工作区。本地验证和密码重置邮件在 [Mailpit](http://localhost:18025) 查看。

桌面端分为侧栏、配置区和右侧手机聊天区。侧栏可以切换助手配置、我的事项、记忆、设置与连接；手机聊天区始终保留。手机端直接显示聊天，通过底部导航进入其他页面。

右侧手机框使用账号的真实主对话。这里发起的操作会修改真实待办和记忆，并按同一规则计算对话额度。消息从网页发起，普通回复不会额外推送微信或 QQ；已绑定渠道的对话会同步显示在网页。

## 配置助手

1. 打开「助手配置」，编辑名字、人设和自定义提示词。
2. 选择需要的能力，点击「保存配置」。
3. 在右侧或手机端「聊聊」中发消息，查看下一轮回复。

| 配置 | 用法与限制 |
| --- | --- |
| 助手名字 | 默认 `JOJO`，去除首尾空格后不能为空，最多 40 字符；保存后更新聊天标题。 |
| 助手人设 | 描述角色、性格和说话方式，最多 1,000 字符；留空沿用默认个人助手设定。 |
| 自定义提示词 | 补充回答习惯，最多 4,000 字符；留空沿用默认规则。 |
| 待办事项 | 默认开启；关闭后，助手不能调用待办查询、创建、修改和删除工具。 |
| 长期记忆 | 默认开启；关闭后，不读取记忆库，也不能调用记忆工具。 |
| 表情回复 | 默认开启；用于网页和 QQ，每轮最多一张，避免连续使用同一张；微信目前只回复文字。 |

例如，人设可以写「温和、直接的生活搭子，回答简洁」；提示词可以写「整理复杂问题时先给结论，再列必要步骤」。这些设置调整表达方式，不增加工具、跨账号访问或执行代码的权限。

配置按账号保存，Web、微信和 QQ 共用。每轮回复开始运行时读取配置；正在运行的回复不会因修改人设或待办/记忆开关而重新开始。表情还会在选择和 QQ 图片发送前检查开关。

切换左侧页面会保留未保存的配置和聊天草稿；刷新或关闭页面前应保存配置，聊天草稿不会自动持久化。保存失败时保留输入并显示错误。

## 管理已有资料

- 「我的事项」可手动创建、编辑、完成和删除待办。截止时间只是事项信息，当前不会触发提醒。
- 「记忆」可查看、添加、修改和删除明确保存的偏好。助手只在用户明确要求时保存记忆。
- 关闭工具开关不会删除资料，也不影响手动管理。关闭记忆或删除某条记忆不会清除聊天中已出现的内容；清空聊天是另一项操作。
- 「设置与连接」管理微信、QQ、账号和聊天历史。清空聊天需要确认，不删除独立保存的待办和记忆，也不恢复当天额度。

## 聊天与渠道状态

聊天支持逐步显示回复、查看已完成操作、停止当前运行和加载更早历史。停止不会撤销已经保存的操作。同一账号的消息按顺序处理；暂时离开网页不会取消已接收的任务。

当前开发预览默认每天 50 次对话，北京时间零点更新。成功接收进入队列的请求会占用额度，包括后续失败或取消；模型未配置、额度不足等被拒绝的请求不计入。平台可调整限额。

微信和 QQ 默认关闭。平台启用后，用户在「设置与连接」扫码绑定微信，或生成一次性指令并在 QQ 私聊发给平台机器人。两个渠道均只处理受支持的私聊文字，文件、语音、识图和群聊尚未开放。微信和 QQ 的真实账号收发仍需验收。

「已同步」表示网页当前能获取账号状态，不代表模型已连接或渠道已送达。渠道记录中的「已提交」仅代表接口接受；「未发送」「失败」「结果不确定」保留在网页，不自动重复发送未知结果。

## 对话服务尚未连接时

默认本地配置未接入模型，仍可保存助手配置、手动管理待办和记忆。聊天提示服务不可用，不会生成模拟回复；发送失败保留输入。

维护者需要选择模型供应商，并按 [开发配置](development.md#配置边界) 设置服务端参数、重启 Web 和 Worker。用户的「自定义提示词」不是模型连接设置。提醒、搜索、文件和文档功能的进度见 [开发与验证](development.md#待完成)。
