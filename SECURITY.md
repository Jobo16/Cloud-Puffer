# Security policy / 安全政策

Only the current `main` branch and the hosted production deployment receive fixes. This project is a development preview; no older release line is supported.

Please report a vulnerability through [GitHub's private reporting form](https://github.com/Jobo16/Cloud-Puffer/security/advisories/new). Include the affected version or commit, reproduction steps, expected impact, and a safe proof of concept. Do not post credentials, personal data, or exploit details in a public issue.

维护者会先确认影响范围，再协调修复与披露。请勿在公开 Issue 中提交密钥、个人资料或可直接利用的细节。
