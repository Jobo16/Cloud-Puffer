# JOJOBOT

**在网页和微信里使用你的个人 AI 助手。**

[English](README.md) | 简体中文

JOJOBOT 是一个面向日常生活的开源个人 AI 助手，帮助你安排事情、整理信息、记住偏好和处理文档。

托管服务计划开放注册，无需邀请码。用户注册后即可使用，无需配置模型或部署服务器。一套共享云端服务支持多个用户，每个人拥有私有的数据和对话。

## 项目状态

**目前处于产品定义阶段。** 仓库中已有产品需求文档、开源代码调研和技术选型建议，尚未提供应用代码、可运行版本或部署说明。以下功能是首版计划，尚未实现。

## 首版计划

- **微信与网页共用一条对话。** 在微信聊过的事情，可以在网页继续处理，共享上下文、记忆、事项和文件。
- **待办、日程与提醒。** 用自然语言创建、修改和管理日常安排。
- **搜索与信息整理。** 获取带来源的信息，保存有用的笔记和链接。
- **个人记忆。** 让助手记住偏好，随时查看、修改或删除。
- **资料与文档。** 保存个人文件、围绕资料提问，生成可以下载的文档。
- **开放注册。** 使用邮箱和密码创建账号，首版免费试用，由平台提供模型并设置使用额度。
- **参考 Apple 的玻璃界面。** 优先复用现成组件，适配桌面与手机，对话和文档保持清晰可读。

首版通过预设工具和 API 执行任务，不需要为每位用户分配独立服务器或常驻容器。其他对话渠道和外部应用连接将在后续版本接入。

## 微信接入

微信通过 iLink 接入。用户在网页登录后扫码，绑定自己的 ClawBot 对话。

回复发回请求发起的渠道，网页展示完整对话。提醒始终保留网页记录；微信无法接收通知时明确显示状态。接口接受请求不等同于用户已收到或已读。

## 托管使用与自行部署

计划中的托管服务面向普通用户，无需配置或部署。开发者选择自行部署时，需要配置运行环境、模型服务、存储和渠道凭据。部署步骤将在代码实现后补充。
